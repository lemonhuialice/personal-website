零售销售运营分析 · 需求预测与备货测算

Walmart 42.2 万条门店-部门周度销售记录

🎯 未来 4 周需求情景

保守 / 基准 / 乐观三档需求测算，用于目标备货覆盖额（Coverage）决策。

方法闭环

  • 数据质量：主键 / 缺失 / 负销售额核查，覆盖 45 门店、81 部门，形成可追溯记录。
  • 滚动审核：验证期选方法、测试期独立检验，避免事后拟合。
  • 三类预测对比：去年同期 / 近期四周平均 / 双指数平滑，逐单元择优。
  • 三种需求情景：保守 / 基准 / 乐观，结合覆盖期与服务水平假设测算目标备货覆盖额。
数据边界说明：公开数据为周度销售额，不含现有库存与在途订单，故只测算需求侧目标覆盖额；门店与部门作为经营单元，用于练习绩效管理与预测审核方法。

📎 输出：5 页月度经营复盘与行动建议，配套经营分析看板（Excel）。

Olist 库存分析与智能补货决策系统

Python + 交互式 Dashboard · 约 10 万笔真实电商订单

基于 Olist 约 10 万笔真实匿名化电商订单，连接订单、商品、卖家和履约时间数据，搭建从需求分析、ABC/XYZ 分类到 SKU 补货建议的完整决策闭环，回答「今天补什么、补多少、为什么」。

+5.89ppFill Rate 提升
-36.2%缺货率下降
-20.9%综合成本下降
+12.5%平均库存缓冲
300SKU · 152卖家 · 40品类
180天真实需求回测

方法闭环

  • 需求：最后 8 周留出验证，逐 SKU 比较季节朴素 / 移动平均 / 动量融合 / Croston 间歇需求，以 WAPE 评估 28 天需求。
  • 供应：以订单批准到卖家交运的真实时长作为提前期代理，计算安全库存、ROP、Order-up-to。
  • 分类与行动：ABC/XYZ 组合，输出 P0–P4 补货行动清单。
  • 交互看板：五页 Dashboard，支持 SKU 搜索、品类 / 优先级筛选、清单导出与情景模拟。
数据边界说明：履约提前期为公开数据中最接近供应响应速度的代理变量（落地应替换为 PO 到收货的采购提前期）；单位成本按售价 65% 建模，结果仅用于策略相对比较，不代表 Olist 实际利润。
